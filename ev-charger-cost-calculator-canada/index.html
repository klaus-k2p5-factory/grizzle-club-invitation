Common questions

What the calculator can—and cannot—tell you.

How much does it cost to install a Level 2 EV charger in Canada?

There is no reliable single Canadian quote. Charger location, cable run, available panel/service capacity, permits, trenching and local labour matter. Hydro One publishes an $800–$3,000 Ontario orientation range before possible upgrades; use an electrician’s site-specific quote.

Does this include a panel or service upgrade?

Only if you enter it as part of your “Installation quote.” The calculator cannot inspect your panel, service or local code requirements.

Should a refundable charger deposit count as a cost?

It affects cash flow, so it appears in upfront cash required. It is excluded from non-refundable cost because refund eligibility and timing are separate. Read the current refund conditions.

Are rebates available everywhere in Canada?

No. Availability and eligibility can depend on province, municipality, utility, building type, equipment, contractor and pre-approval timing. An unchecked rebate is never subtracted by this tool.

Is a Club-supplied charger mine if I cancel?

Under the current general Club ownership terms, the supplied charger remains United Chargers property during membership and must generally be returned when membership ends. Full-program termination has separate rules. Current official terms control.

Can I use this if I rent or live in a condo?

Yes for a preliminary estimate, but obtain landlord, condo/strata, property-manager and electrical approvals before buying equipment or relying on an incentive.
